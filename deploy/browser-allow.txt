# The websites Teeny's browser may open, one host per line. bin/spine writes
# this list into the core's config at every boot as
# `[http_request] allowed_domains`, which the browser and OpenHuman's own
# `http_request` tool share, and hands/tasks refuses a task whose start_url
# is not on it.
#
# Reviewed by the operator, never by Teeny: it lives in deploy/, outside the
# brain Teeny edits. A host matches itself and its subdomains. No wildcards
# ("*" would let the browser go anywhere; OpenHuman strips it anyway).

github.com
