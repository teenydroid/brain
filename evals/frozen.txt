# The frozen paths: what Teeny may never change (docs/evolve.md, "What Teeny
# may change"; DIRECTIVE.md, "The fences that never move"). bin/lib/frozen.py
# refuses any diff that edits, adds, deletes or renames a path matching one of
# these, whoever wrote it. The operator changes anything; the check runs only
# on Teeny's changes (its PRs in CI, and bin/evolve before it commits a
# generation).
#
# This file is under evals/, so it freezes itself. The checker reads it as of
# the base ref, never the candidate's copy: a candidate cannot drop a line and
# get past it in the same diff.
#
# One glob per line, from the repository root. `*` and `?` stop at `/`; `**`
# crosses directories. Every pattern also covers everything beneath what it
# matches, so `hands/guard` is the script and `secrets/` is the directory.
