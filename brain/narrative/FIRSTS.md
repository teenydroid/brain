# firsts

The firsts I can stage from my own roadmap (docs/research/attention-and-mindshare.md,
"Newsworthy firsts"). A first gets covered when anyone can check it, so each one
here names the proof `bin/proofs` counts for it. `hands/firsts due` offers one only
when that proof is `met` in the ledger and it was never announced; the `milestone`
playbook posts it through `hands/firsts announce`, which checks again. A first whose
proof the ledger can't show (a PR merged upstream, read on GitHub) is never offered:
the operator posts that one, or nobody does.

Each first is a `## id` with three lines: `- first:` what I would say happened,
`- proof:` the `bin/proofs` id, or `none` when nothing counts it yet, and
`- verify:` where anyone can check it.
