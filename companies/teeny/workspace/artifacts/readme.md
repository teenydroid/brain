# Deliverables

Every file an agent published with `publish_artifact`, filed as `artifacts/<agent>/<task>/<path>`. A run that published nothing leaves nothing here — that is a real outcome, not a gap: plenty of work (a question answered, a check run) produces no file.

Each note here is the **current** body of a deliverable. Its version history, and who revised each version, live on the artifact record the card's Artifacts tab shows.

Editing a note here is recorded against that history as a human edit, which is deliberate — the gap between what the agent produced and what a person had to fix is the point. Do not hand-create files here: nothing links them to a deliverable, and they will read as artifacts that are not.
